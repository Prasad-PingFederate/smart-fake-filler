# Smart Fake Filler

Chrome extension that fills forms with fake data that follows the field rules (dosage like 500mg, SWIFT, IBAN, dates, patterns, length limits).

## Download and load

1. On this GitHub page click the green **Code** button, then **Download ZIP**.
2. Unzip it.
3. Open the folder named `smart-fake-filler-main`.
4. Confirm `manifest.json` is directly inside that folder.
5. Chrome: `chrome://extensions` → Developer mode ON → **Load unpacked** → select `smart-fake-filler-main`.
6. Do not select `Downloads\smart-fake-filler` or any parent folder.
7. Refresh the website tab, then click the extension icon → **Fill Form Smartly**.
